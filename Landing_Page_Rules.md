# IDPhoto Pro Landing Page Rules

## Goal

Maximize trust, clarity and App Store conversions.

## Structure

1.  Hero
2.  Official Formats
3.  Flexible Export
4.  Privacy First
5.  FAQ
6.  Final CTA

## Hero

-   One phone mockup only.
-   One print sheet only.
-   One CTA.
-   Headline \<= 3 lines.
-   Description \<= 2 lines.
-   4 benefit bullets maximum.

## Section Rules

Each section must contain: - 1 headline - 1 supporting paragraph - 1
primary visual - \<=3 supporting callouts

## Visual Focus

Hero → Phone Formats → World Map Export → Print Preview Privacy → Shield

Never reuse the same phone screenshot.

## Copy Style

-   Short sentences.
-   Active voice.
-   Benefit first.
-   Avoid AI buzzwords.

## Trust Signals

-   100+ Official Formats
-   On-device Processing
-   No Upload
-   No Tracking
-   Digital & Print Ready

## UX

Whitespace is a feature. Remove before adding.
