# IDPhoto Pro Brand Guideline

## Brand Personality

Professional Reliable Minimal Privacy-first Global

## Voice

Clear, confident, concise.

## Color

Primary: #111827 Secondary: #6B7280 Brand Blue: #2563EB Success: #10B981
Background: #FFFFFF Soft: #F8FAFC

## Typography

Headings: Bold Body: Regular Large spacing.

## Components

Buttons: - Radius 14px - Height 56px

Cards: - White - Radius 20px - Light border - Soft shadow

Icons: - Outline - Blue icon - Soft background

## Imagery

-   Real app screenshots
-   Bright lighting
-   Minimal decoration
-   White background
-   One hero object per section

## Do

-   Use whitespace.
-   Highlight one key message.
-   Keep layouts balanced.

## Don't

-   Multiple phones in one section.
-   Heavy gradients.
-   Excessive blue.
-   Crowded information.
-   Decorative elements without purpose.
