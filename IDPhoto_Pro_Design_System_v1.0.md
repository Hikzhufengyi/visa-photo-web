# IDPhoto Pro Website Design System v1.0

## Design Philosophy

Build a premium, modern landing page inspired by **Apple, Stripe, Linear
and Notion**.

### Principles

-   Premium
-   Minimal
-   Trustworthy
-   Professional
-   Privacy-first
-   Spacious
-   Simple over flashy

# Visual Rules

Only **ONE** hero illustration per section.

Hero → Phone

Formats → World Map

Export → Print Sheet

Privacy → Lock / Shield

Never repeat the same phone screenshot.

------------------------------------------------------------------------

# Information Density

Each section should contain:

-   One headline
-   One description
-   One primary illustration
-   Up to three supporting elements

When in doubt:

**Remove instead of add.**

------------------------------------------------------------------------

# Final Design Checklist

Before adding any new UI element, ask:

1.  Does it improve user understanding?
2.  Is it the primary visual of this section?
3.  Can an existing element be removed?
4.  Can users understand this section in under 3 seconds?

If any answer is **No**, simplify instead of adding more.
